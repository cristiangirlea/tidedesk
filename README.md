# TideDesk

**Remote access to your own computers.** Screen sharing, keyboard and mouse control,
system audio, files and chat, for Windows, with an experimental Android viewer.
Sessions run directly between the two computers, never through a relay.

**Free for personal, non-commercial use** under the [TideDesk Freeware License](LICENSE).
Business use needs a TideDesk licence: see [tidedesk.app](https://tidedesk.app).

## Download

- **Windows:** the [Microsoft Store](https://apps.microsoft.com/detail/9PLH1HWXHB3Q), or the ZIP on the
  [releases page](https://github.com/cristiangirlea/tidedesk/releases): unzip and run
  `tidedesk.exe` on both computers.
- **Android (experimental):** the APK on the [releases page](https://github.com/cristiangirlea/tidedesk/releases).

Each release lists SHA-256 checksums for its files.
